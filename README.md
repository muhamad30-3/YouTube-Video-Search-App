# YouTube Video Search App

## Description

This Android application allows users to search for YouTube videos using the YouTube Data API.

## Features

* Search YouTube videos by keyword.
* Display results using RecyclerView.
* Show video title, description, channel name, publish date, and thumbnail.
* Load images using Glide.
* Show loading indicator while fetching data.
* Handle empty search, no results, and network errors.

## Technologies Used

* Android Studio
* Java
* Retrofit
* RecyclerView
* Glide
* YouTube Data API

## Setup

1. Clone the repository.
2. Open the project in Android Studio.
3. Add your YouTube API Key.
4. Run the application.
